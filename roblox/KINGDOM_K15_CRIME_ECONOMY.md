# K15 Crime / Bandit Economy

K15 is a read-only economic pressure model for crime and bandit incentives.

It projects scarcity pressure, theft risk, bandit incentive, bounty pressure and security need from existing colony/Kingdom signals. It does not create bandits, move agents, resolve combat, generate routes, or mutate authoritative stock.

Runtime state: `Workspace.AstraKingdomState/K15CrimeEconomy`.

Integration rule: future bandit/combat systems may consume K15 pressure as demand/intent, but physical spawning, navigation and combat remain outside Kingdom authority.
