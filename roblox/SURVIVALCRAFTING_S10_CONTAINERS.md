# SurvivalCrafting S10 — Station Containers

Standalone multi-bay container runtime for storage/input/fuel/output layouts with slot limits, item-tag filters and idempotent add/remove transaction IDs.

Profiles cover StorageBox, Campfire, Furnace, Workbench, Anvil, Quarry and Sawmill. S10 does not bind these containers to real Structures or legacy Agent inventory yet.

Acceptance target: `Workspace.AstraSurvivalCraftingState.S10Containers.S10Status == "PASS"`.
