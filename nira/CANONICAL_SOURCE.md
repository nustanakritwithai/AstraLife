# Nira Living Society (R2) — GitHub Pages mirror

This folder hosts the standalone **The Realm of Nira** browser atlas and 30 NPC local Utility AI simulation with bounded social memories, directional trust, and provenance-aware reported market facts.

Canonical code and world data are maintained in [Kingdom-sandbox](https://github.com/nustanakritwithai/Kingdom-sandbox/tree/main/world/nira). This folder is a presentation mirror; no original AstraLife runtime modules or world state were modified.

**Limitations:** local browser simulation only, no continuously running server, no LLM inference, no pixel-collision-verified routes. R1 local saves are migrated on first R2 visit and the legacy storage key is retained.
